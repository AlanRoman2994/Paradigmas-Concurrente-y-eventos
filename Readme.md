# Paradigmas de Programación

Este proyecto contiene ejemplos de dos paradigmas:

- **Concurrente (Python)**: ejecución de múltiples tareas simultáneas usando `asyncio`.
- **Dirigido por eventos (JavaScript)**: respuesta a estímulos externos como clics.

## Ejecución
- Python: `python concurrente.py`
- JavaScript: abrir `evento.html` en el navegador.
